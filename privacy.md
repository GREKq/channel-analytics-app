# Privacy Policy - Channel Analytics

Channel Analytics is a personal tool used by its owner to read the statistics of the owner's own YouTube channels.

**What it accesses.** With the owner's explicit consent, it reads the owner's own YouTube channel data (YouTube Data API v3 and YouTube Analytics API, read-only access): views, watch time, audience retention, traffic sources, subscribers and similar channel statistics.

**How data is used.** The data is used only to analyse the owner's channels and improve the owner's content.

**Storage and sharing.** Data and access tokens are stored only on the owner's own computer. They are not sold, shared, or disclosed to any third party, and are not used for advertising.

**Revoking access.** Access can be revoked at any time at https://myaccount.google.com/permissions
